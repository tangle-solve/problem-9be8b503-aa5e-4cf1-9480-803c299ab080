### CLIM-000260: The Holocene temperature conundrum
- **Subfield:** Paleoclimate and long-timescale dynamics
- **Open:** Reconcile reconstructions showing a mid-Holocene thermal maximum and later cooling with different simulated trends. Quantify seasonal sampling, calibration, coverage, and missing-feedback contributions.
- **Status:** Named in the 2010s; Kaufman and Broadman (2023) supported a mild thermal maximum while finding additional evidence necessary.
- **Type:** data
